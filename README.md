Tensegrity Supplement Fetcher (prototype)

A minimal prototype to record located supplementary datasets (CSV/JSON) referenced by articles or webpages. Enter metadata and columns, then export the collected records as a JSON file into a data/ directory locally.

Usage:
- Open index.html in a browser.
- Add dataset entries (title, URL, format, columns/types).
- Click Save to add to the in-page list.
- Click Export to download records.json, which you can move into a data/ directory in a repository.

Notes:
- This prototype does not fetch URLs automatically. Use it to collect, verify, and document dataset locations before manual download.
- Keep records of access dates and any verification steps in the notes field.
